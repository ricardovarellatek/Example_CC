# Example_CC

Projeto de exemplo criado para demonstrar o uso do [Claude Code](https://claude.com/claude-code) em tarefas de desenvolvimento de software, como a geração de documentação e o versionamento com Git.

## Sobre

Este repositório serve como ponto de partida e área de testes para experimentar fluxos de trabalho assistidos por IA diretamente no terminal. Neste momento ele contém apenas este `README.md`; o código-fonte será adicionado conforme o projeto evoluir.

## Pré-requisitos

- [Git](https://git-scm.com/) instalado e configurado
- Uma conta no [GitHub](https://github.com/)
- (Opcional) [Claude Code](https://claude.com/claude-code) para reproduzir os fluxos de exemplo

## Como usar

Clone o repositório:

```bash
git clone https://github.com/ricardovarellatek/Example_CC.git
cd Example_CC
```

## Estrutura do projeto

```
Example_CC/
└── README.md    # Documentação do projeto
```

## Contribuindo

1. Faça um fork do repositório
2. Crie uma branch para a sua alteração (`git checkout -b minha-alteracao`)
3. Faça o commit (`git commit -m "Descreve a alteração"`)
4. Envie a branch (`git push origin minha-alteracao`)
5. Abra um Pull Request
